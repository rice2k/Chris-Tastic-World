# Chris-tastic World — Project Notes

## Project overview
A retro 1998–2003-inspired children's science activity site featuring bright lab-themed art, purple/green/yellow design, and a classic old-web portal layout.

## Existing website package
The most recent full local export is named `chris_tastic_world_final_polished_checked.zip`. It contains 162 entries: HTML pages, CSS, JavaScript, and many PNG images. The GitHub repository needs the **extracted** files, not just a ZIP archive, to publish via GitHub Pages.

## Site features
- 55 experiment pages with instructions, supplies, difficulty blocks and printing
- Experiment search, difficulty filtering, random experiment selection
- Homepage links to Experiments
- 10 video slots (YouTube IDs not yet populated)
- Under-construction image placeholders in gallery
- Child-friendly scientific resources on Links page
- Neon-green sidebar visitor counter

## Remaining work before calling this site live
1. Upload all extracted site files, preserving relative paths and image filenames.
2. Check that `index.html`, `assets/style.css`, and `assets/site.js` exist at expected locations.
3. Enable GitHub Pages under repository Settings → Pages, source **GitHub Actions**.
4. Check Actions logs, test navigation and experiment pages in the deployed website.
5. Verify whether the third-party visitor counter behaves correctly on the public host.

## Privacy
Repository is currently public. GitHub Pages on free personal accounts normally requires the repository to remain public. Never place passwords, private documents, access tokens, or personal secrets in this public repository.
